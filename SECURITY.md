# Security

QuantumBench is an unaudited research/developer prototype, not a cryptographic certification, account authenticator or custody system. The stateless verifier holds no funds. Contract ML-DSA support does not make network transaction signatures post-quantum secure.

Report suspected vulnerabilities privately to the organization owner through GitHub before posting sensitive details. No staffed response or response-time guarantee is promised. Use only public test inputs. The loopback API restricts Host/Origin, caps JSON input at 1 MiB and limits local measurements to 1–200 iterations and 16 positive vectors. It uses fixed testnet endpoints and never reads signing secrets. Only the explicit opt-in pilot signs disposable testnet transactions, with private identities outside source checkouts.
