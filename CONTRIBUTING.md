# Contributing to QuantumBench

Start with one measurement or conformance question, its input provenance and an explicit evidence channel. Include a regression demonstrating the problem and preserve raw observations. Never relabel local timings as host resources or network capacity. Keep invalid-input outcomes separate from cryptographic rejection.

Candidate work includes authoritative-vector ingestion with licensing/provenance, randomized benchmark ordering, a compatible Protocol 30 Wasm pipeline, capability-gated native simulations and report comparison by matching runtime/calibration. No issue should promise production post-quantum account migration.

Clone sibling repositories and run README checks. Contract changes require both feature configurations. Regenerating vectors changes randomized signatures and keys; update the contract copy deliberately and rerun both implementations. Do not commit private keys, production signing material or confidential payloads.
